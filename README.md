# OPC Master

Bienvenido a mi repositorio enfocado en OPC UA, automatización industrial moderna y microservicios industriales usando TypeScript, Node.js y Docker.

Este proyecto no es solo teoría, con el pretendo dos objetivos principales:

- Brindar una base solida de microservicios listos para trabajar con OPC, en entornos industriales reales
- Servir de fundamentos para que **personas del area de IT**, que no están familiarizadas con el trabajo de OT, tengan los fundamentos para conectarse a PLC's y maquinaria por medio de OPC
- Servir de fundamento para que **personas del area  de OT**, que no están familiarizadas con el desarrollo de microservicios, puedan desarrollar aplicaciones de extracción y publicación de datos.

Con esto en mente, puedes usar este repositorio para cualquiera de las siguientes dos cosas:

1. Aprender a crear microservicios profesionales que funcionen como cliente o servidor OPC
2. Utilizar los microservicios ya existentes en este repo como base para desarrollar lo que tu necesitas, partiendo de  una base profesional y estructurada.

## ¿Por qué existe este proyecto?

La mayoría del contenido industrial sigue atrapado en:
- Software legacy
- Tutoriales desactualizados
- Ejemplos irreales
- Integraciones cerradas

OPC Master busca enseñar automatización industrial utilizando herramientas modernas de desarrollo:
- TypeScript
- Node.js
- Docker
- Microservicios
- MQTT
- APIs
- IIoT

## Estado del proyecto

Este repositorio está en desarrollo activo. Nuevos microservicios, ejemplos y laboratorios serán agregados progresivamente como parte de la serie OPC Master.

## ¿Cual es tu objetivo?

A partir de aqui, tienes dos caminos:

**A)** Puedes ver la **Lista de microservicios**, acceder y utilizar el que necesites. Encontraras toda su documentación en el readme de cada microservicio. 

**B)** Seguir el **Roadmap de aprendizaje**, para ir realizando todos los ejercisios paso a paso, y convertirte en un experto.
